## 2. 稳定公开接口

计划公开接口：

```python
audit_rul_dataset(manifest, config) -> DatasetAudit
build_rul_records(manifest, assessment_packets, contract, split) -> list[RULRecord]
train_rul_model(train_records, validation_records, config) -> RULModel
predict_rul(records, model) -> DataFrame
evaluate_rul(predictions, labels, config) -> dict
```

推理函数只能接收遥测、运行时可知工况、冻结 HI 和模型对象，不能读取 `ground_truth/`、场景标签或未来数据。

## 4. 本地与远程边界

本地无显卡不构成阻塞。职责划分：

- 本地：合同测试、数据审计、tiny CPU smoke、配置冻结、结果审核；
- 远程：GPU smoke、正式训练、多种子实验、显存与性能记录；
- 仿真数据生成仍由具有 MATLAB/Simulink 环境的一侧执行，GPU 不加速该步骤；
- 远程代码和数据通过哈希确认一致，不通过复制目录名推断版本。

所有配置使用相对路径或 CLI 参数，不写死 `C:\Users\...`。训练程序支持 `--device cpu|cuda|auto`、AMP 开关、固定种子、checkpoint 和 resume。CPU 与 GPU 可以存在容许的浮点差异，但数据划分、样本键和配置哈希必须一致。

## 5. 推荐远程流程

```text
本地全量测试
→ 生成代码/配置/数据哈希清单
→ 上传服务器
→ 创建隔离 Python 3.11 环境
→ 安装与服务器 CUDA 匹配的 PyTorch
→ audit --no-train
→ tiny GPU smoke
→ 冻结正式配置
→ 正式训练与断点保存
→ 下载输出和哈希清单
→ codex 只读复核
```

不得在正式训练脚本内部临时下载安装依赖。PyTorch/CUDA 安装命令需根据服务器驱动确定，不能预先硬编码一个未经核对的 CUDA 版本。

允许新增合成多种子 Slurm 作业或 job array。GPU smoke 必须先在 `interactive` 分区完成，并显式请求 `gpu:3090:1` 或 `gpu:3080ti:1`；较长的合成实验进入 `normal` 分区。`03_train.sbatch` 继续代表真实数据正式训练，缺少经审核的标签闸门时必须拒绝执行，不得通过改脚本或创建 `TRAINING_GATE_APPROVED` 绕过。

完整 Goal 指令见 `文本/11_GLM5.3_Goal模式全模型合成实验提示词.md`。
