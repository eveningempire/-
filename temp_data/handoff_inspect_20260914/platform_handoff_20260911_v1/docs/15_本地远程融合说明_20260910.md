## 3. 本地兼容修正

远程代码在 Linux/Slurm 上验证，本地首次联合测试暴露了 Windows 兼容问题。本次只修改非冻结文件：

- `evaluation/latency.py`：POSIX 使用 `resource`，Windows 使用 `GetProcessMemoryInfo`；
- `evaluation/reporting.py`：用跨平台主机名 API，并统一源码哈希键为 POSIX 相对路径；
- `training/distillation.py`：使用系统临时目录，不再写死 `/tmp`；
- `tests/test_latency.py`：增加 Windows 回归测试。

冻结文件 `contracts.py`、`data/labels.py`、`data/splits.py` 的 SHA-256 与 R0 登记值一致。
