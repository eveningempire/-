# 检测频率控制UI使用指南

## 概述

检测频率控制功能已集成到系统管理页面的系统状态监控中，用户可以通过直观的Web界面配置和管理检测频率设置，从而优化大量数据导入时的检测性能。

## 访问路径

1. 登录系统后，点击左侧导航栏的 **系统管理**
2. 选择 **系统状态** 页面
3. 滚动到页面底部，找到 **检测频率控制设置** 卡片

## 功能特性

### 1. 基本设置

- **启用检测频率控制**：开关控制是否启用检测频率控制功能
- **检测模式**：选择检测频率模式，包括：
  - 自适应模式（推荐）
  - 高频模式
  - 中频模式
  - 低频模式
  - 禁用模式

### 2. 固定模式设置

当选择高频、中频或低频模式时，可以配置对应的检测间隔：

- **高频检测间隔**：1-3600秒，默认1秒
- **中频检测间隔**：1-3600秒，默认30秒
- **低频检测间隔**：1-3600秒，默认60秒

### 3. 自适应模式设置

自适应模式会根据数据量自动调整检测间隔，可以配置以下参数：

#### 数据集阈值
- **小数据集阈值**：100-5000帧，默认1000帧
- **中数据集阈值**：1000-10000帧，默认5000帧
- **大数据集阈值**：5000-50000帧，默认10000帧

#### 检测间隔
- **小数据集间隔**：1-60秒，默认1秒
- **中数据集间隔**：10-300秒，默认30秒
- **大数据集间隔**：30-600秒，默认60秒

### 4. 性能预览

系统会根据当前配置显示预期的性能提升效果：

- **高频模式**：检测比例约100%，无性能提升
- **中频模式**：检测比例约3-5%，性能提升95-97%
- **低频模式**：检测比例约1-2%，性能提升98-99%
- **自适应模式**：根据数据量智能调整，性能提升95-99%

## 操作说明

### 保存配置

1. 根据需要调整各项参数
2. 点击 **保存配置** 按钮
3. 系统会显示保存成功提示

### 重置默认

1. 点击 **重置默认** 按钮
2. 确认重置操作
3. 配置将恢复为系统默认值

### 测试配置

1. 点击 **测试配置** 按钮
2. 系统将验证当前配置的有效性
3. 显示测试结果

## 配置建议

### 小数据量场景（<1000帧）
- 推荐使用：**自适应模式** 或 **高频模式**
- 检测间隔：1-5秒
- 预期效果：保持高精度检测

### 中等数据量场景（1000-10000帧）
- 推荐使用：**自适应模式** 或 **中频模式**
- 检测间隔：10-60秒
- 预期效果：平衡精度和性能

### 大数据量场景（>10000帧）
- 推荐使用：**自适应模式** 或 **低频模式**
- 检测间隔：30-120秒
- 预期效果：显著提升处理速度

## 注意事项

1. **配置生效**：配置更改后立即生效，无需重启系统
2. **精度权衡**：检测频率越低，可能遗漏的异常越多
3. **数据完整性**：系统会确保选择第一帧和最后一帧进行检测
4. **兼容性**：可以随时禁用频率控制，恢复逐帧检测

## 故障排除

### 配置不生效
- 检查是否点击了保存配置按钮
- 确认配置格式正确
- 查看浏览器控制台是否有错误信息

### 性能提升不明显
- 确认数据量是否达到阈值
- 检查检测模式设置是否正确
- 验证时间间隔配置是否合理

### 检测结果异常
- 检查数据时间戳是否正确
- 确认时间范围设置合理
- 考虑调整检测间隔
