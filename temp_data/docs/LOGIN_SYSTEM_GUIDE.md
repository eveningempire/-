# 登录系统使用指南

## 概述

基于模型的寿命预测系统现已启用账号密码登录功能，支持多角色用户管理。

## 功能特性

### 🔐 用户认证
- **账号密码登录**：支持用户名和密码登录
- **会话管理**：基于Django Session的认证机制
- **自动登出**：登录过期自动跳转到登录页面
- **安全退出**：支持安全登出功能

### 👥 用户角色
- **管理员 (admin)**：拥有所有权限，可以管理用户账户
- **普通用户 (user)**：基础用户，可以查看数据

### 🛠️ 用户管理
- **创建用户**：管理员可以创建新用户账户
- **编辑用户**：修改用户信息和状态
- **删除用户**：删除不需要的用户账户
- **状态管理**：启用/禁用用户账户

## 快速开始

### 1. 创建管理员账户

首次使用系统时，需要创建管理员账户：

```bash
# 激活虚拟环境
.venv\Scripts\activate

# 运行创建管理员脚本
python scripts/create_admin.py
```

脚本会自动创建以下账户：
- **管理员**：`admin` / `admin123456`
- **普通用户**：`user1` / `user123`
- **普通用户**：`user2` / `user123`

### 2. 启动系统

```bash
# 启动后端服务
python manage.py runserver

# 启动前端服务（新终端）
cd frontend
npm run dev
```

### 3. 登录系统

1. 访问 `http://localhost:3000`
2. 系统会自动跳转到登录页面
3. 输入用户名和密码
4. 点击"登录"按钮

## 用户管理功能

### 访问用户管理页面

1. 登录系统后，点击左侧导航栏的 **系统管理**
2. 选择 **用户管理**
3. 只有管理员可以访问此页面

### 创建新用户

1. 在用户管理页面点击 **创建用户** 按钮
2. 填写用户信息：
   - **用户名**：3-20个字符，唯一标识
   - **邮箱**：有效的邮箱地址
   - **姓名**：用户真实姓名
   - **角色**：选择用户角色
   - **密码**：至少6个字符
   - **确认密码**：再次输入密码
   - **状态**：启用或禁用账户
3. 点击 **保存** 完成创建

### 编辑用户

1. 在用户列表中点击 **编辑** 按钮
2. 修改需要更新的信息
3. 点击 **保存** 完成更新

### 删除用户

1. 在用户列表中点击 **删除** 按钮
2. 确认删除操作
3. **注意**：管理员账户不能被删除

## 安全建议

### 密码安全
- 使用强密码（包含大小写字母、数字和特殊字符）
- 定期更换密码
- 不要在多个系统使用相同密码

### 账户管理
- 及时删除不再使用的账户
- 定期检查用户访问记录
- 对敏感操作启用二次确认

### 系统安全
- 定期备份用户数据
- 监控异常登录行为
- 及时更新系统安全补丁

## 故障排除

### 登录问题

**问题**：无法登录系统
**解决方案**：
1. 检查用户名和密码是否正确
2. 确认用户账户是否被启用
3. 清除浏览器缓存和Cookie
4. 检查网络连接

**问题**：登录后立即被登出
**解决方案**：
1. 检查浏览器是否支持Cookie
2. 确认系统时间是否正确
3. 检查后端服务是否正常运行

### 用户管理问题

**问题**：无法创建用户
**解决方案**：
1. 确认当前用户具有管理员权限
2. 检查用户名是否已存在
3. 确认邮箱格式是否正确
4. 检查密码是否符合要求

**问题**：无法删除用户
**解决方案**：
1. 确认要删除的用户不是管理员
2. 检查用户是否有关联数据
3. 确认当前用户具有删除权限

## API接口

### 认证接口

```http
POST /api/v1/users/login/
Content-Type: application/json

{
    "username": "admin",
    "password": "admin123456"
}
```

```http
POST /api/v1/users/logout/
```

### 用户管理接口

```http
GET /api/v1/users/                    # 获取用户列表
POST /api/v1/users/register/          # 创建用户
GET /api/v1/users/{id}/               # 获取用户详情
PUT /api/v1/users/{id}/               # 更新用户
DELETE /api/v1/users/{id}/            # 删除用户
GET /api/v1/users/me/                 # 获取当前用户信息
```

## 技术架构

### 前端
- **Vue 3** + **Element Plus**：用户界面
- **Vue Router**：路由管理和守卫
- **Axios**：HTTP请求和拦截器
- **LocalStorage**：本地状态存储

### 后端
- **Django**：Web框架
- **Django REST Framework**：API框架
- **Django Session**：会话管理
- **自定义用户模型**：扩展用户字段

### 安全机制
- **CSRF保护**：防止跨站请求伪造
- **密码加密**：使用Django内置密码哈希
- **会话超时**：自动清理过期会话
- **权限控制**：基于角色的访问控制
