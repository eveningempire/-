# 结构与分析一致性说明

“结构与知识 → 运载器 PBS 结构树”保存单机产品节点；“数据管理”允许管理员将每个数据集关联到一个 PBS 单机产品。关联是显式编号，不再根据自由填写的系统、部件文本推测结构归属。旧数据保留未关联状态，需在数据管理中逐条确认。

数据管理默认隐藏已明确登记为仿真“派生参数”的记录，打开“显示派生参数”开关可预览、下载及管理，文件与数据集登记继续保留供寿命预测配对使用。切换开关会清空当前表格选择。Hier14 的单个及批量选择排除这些派生数据，改用其他诊断算法时仍可选择；从其他算法切回 Hier14 会移除已选的派生数据。分类仅使用 `source=simulation` 和 `component=派生参数` 的明确记录，不猜测文件名，未分类旧数据继续显示。

“多信号流图”从所选 CSV 的前 1000 行读取数值列，用于查看数据集、已登记 PBS 节点与分析模块的接入关系。趋势图对每路信号在当前预览区间单独缩放至 0–1，并在提示中显示原始数值。该图不执行诊断，也不生成健康或寿命结论。

健康评估页面的 CDPCA-GA、AE-GMM 会根据当前数据集的数值信号计算相对健康指数；系统级 GCN + RBD 由所选数据集的结果融合。页面展示 PBS 关联、实际返回的 HI 序列和模型状态。算法当前属于开发评估路线，未完成具体型号和工况标定。PBS 关联用于追踪数据归属，不自动改变算法输入或计算公式。

单机级支持“单个评估”和“批量评估”。批量可选择最多 100 份 CSV，逐份独立计算，展示成功/失败、健康指数、健康等级及样本数；点击“查看详情”切换该文件的健康趋势。某份数据失败不会阻断其他文件，也不会将多份单机数据自动融合为系统级结果。接口为 `POST /api/v1/health-assessment/batch-evaluate/`，输入 `dataset_ids` 和 `algorithm`（`cdpca_ga` 或 `ae_gmm`）。

系统级选项固定为“控制”和“动力”，只能选择同一系统的数据集进行融合。诊断算法目录已移除压力阈值示例，现有内置诊断为 Hier14、MSFG + TEAMS-RT、PCA-iForest。

寿命预测的 health-main 集成模型已于 2026-10-09 增加仿真数据适配，替代此前“CSV 必须自带 HI”的限制。派生 CSV 根据所选部件提取对应 P 参数，按训练时的 2 秒窗口、1 秒步长及特征顺序，通过冻结的 scaler/PCA 和训练归一化范围生成 HI；原始状态量可读取登记记录中可核验的同次派生 CSV，要求两份 Time 时间轴一致。没有可靠配对时明确报错，不根据相似文件名推断。已有 HI 列仍可直接输入，但须人工确认其模型兼容性。至少需要 51 个 HI 窗口，预测单位为秒。健康评估页面刚计算出的通用 HI 不会自动写回 CSV，也不应直接视作 health-main 所需的 HI。

寿命页不再默认选择 14 号模型；如数据集已关联 PBS 产品，而产品名称与所选部件模型不同，页面会阻止运行。未关联 PBS 的数据仍可手动选择模型，但必须人工核对。生成的 HI 裁剪至 0–1，并披露裁剪比例及输入来源；裁剪严重说明新数据超出训练归一化范围，本次适配只证明能执行预测，不代表真实剩余寿命精度已经标定。输入契约、部件映射和验证记录见 [健康寿命预测数据适配验证](./健康寿命预测数据适配验证_20261009.md)。

当前结构模板覆盖 32 个节点，但寿命模型列表中的部分部件不在模板中，且两套命名尚未完全统一。对这类部件应先扩充 PBS 模板，再建立数据集关联；不能仅凭同名或类似名称推定模型对应关系。正式工程应用还需要测点到 PBS 产品、模型输入 HI 定义、部件模型编号和工况的明确映射表及标定数据。
