# 结构与分析一致性说明

“结构与知识 → 运载器 PBS 结构树”保存单机产品节点；“数据管理”允许管理员将每个数据集关联到一个 PBS 单机产品。关联是显式编号，不再根据自由填写的系统、部件文本推测结构归属。旧数据保留未关联状态，需在数据管理中逐条确认。

“多信号流图”从所选 CSV 的前 1000 行读取数值列，用于查看数据集、已登记 PBS 节点与分析模块的接入关系。趋势图对每路信号在当前预览区间单独缩放至 0–1，并在提示中显示原始数值。该图不执行诊断，也不生成健康或寿命结论。

健康评估页面的 CDPCA-GA、AE-GMM 会根据当前数据集的数值信号计算相对健康指数；系统级 GCN + RBD 由所选数据集的结果融合。页面展示 PBS 关联、实际返回的 HI 序列和模型状态。算法当前属于开发评估路线，未完成具体型号和工况标定。PBS 关联用于追踪数据归属，不自动改变算法输入或计算公式。

寿命预测的 health-main 集成模型要求 CSV 自带符合模型定义的 HI 列，至少 51 行，并选择相应部件模型。健康评估页面刚计算出的 HI 不会自动写回 CSV，也不应直接视作 health-main 所需的 HI。寿命页不再默认选择 14 号模型；如数据集已关联 PBS 产品，而产品名称与所选部件模型不同，页面会阻止运行。未关联 PBS 的数据仍可手动选择模型，但必须人工核对。

当前结构模板覆盖 32 个节点，但寿命模型列表中的部分部件不在模板中，且两套命名尚未完全统一。对这类部件应先扩充 PBS 模板，再建立数据集关联；不能仅凭同名或类似名称推定模型对应关系。正式工程应用还需要测点到 PBS 产品、模型输入 HI 定义、部件模型编号和工况的明确映射表及标定数据。
