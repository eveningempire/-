# 离线与实时故障数据说明（2026-10-10）

## 数据来源

两条入口都使用用户提供的《一院项目.zip》中的同一套仿真资产：`一院项目/simulate/rocket_sim.slx`、`simulate_core.py` 和原始界面 `simulate_main.py`。已安装模型与压缩包中的 `rocket_sim.slx` SHA256 一致：`2fa9a6644a1f45fbe6a6a198037f0771ccfcc8860220984f17c442e3ad05f85a`。

平台将表单中的子系统、故障类型、注入时刻、恢复时刻和飞行次数传给 `simulate_core.run_simulation()`。核心程序清空全部故障块，设置对应故障的 Constant、Step1、Step2，再调用 MATLAB Engine 的 `eng.sim()`，最后导出 `scope_data.csv`（29 路原始状态量）和 `P_values.csv`（17 路派生参数）。`Time` 与 `FaultFlag` 不作为模型特征。

## 两个入口的区别

- **离线故障数据集生成**：提交后执行一次完整仿真，完成后登记 CSV 到数据管理，适合生成可重复选择、下载和批量分析的数据集。
- **实时故障注入**：当前实现是后台任务队列、阶段进度和结果跟踪入口。它仍调用同一模型完成一次完整 480 秒求解，求解完成后才导出并登记 CSV；当前不是 Simulink 求解过程中的逐点在线遥测流。真正逐点实时接入使用“遥测数据监测”中的 MATLAB 会话和 `phm_send_telemetry` 接口。

因此，当前两者在算法和仿真生成逻辑上相同，主要差别是任务入口和交互方式。两者不会自动生成不同版本的数据。

## 算法正确性边界

仿真调用链、故障块映射、CSV 字段、时间轴和闭区间故障标签已经做了代码校验和真实运行验证，接口层面正确。模型本身保存为 R2023a，而本机 MATLAB 为 R2022b，平台开启了兼容加载；三次真实求解成功，但正式验收仍应在 R2023a 或由甲方确认跨版本差异。

故障诊断 Hier14 在新生成数据上可以运行并检出测试中的故障窗口，但报告结果显示正常窗口误报率约 19.70%，不能称为全部故障类别已准确验收。MSFG + TEAMS-RT、PCA-iForest 目前也只是可运行的通用异常检测，尚未完成一院 13 类故障的测点映射和工况标定。

健康评估已经修正为相对正常基线的方向：接近正常时 HI 接近 1，偏离正常时下降，状态恢复时允许回升；这属于无监督相对评估，不等于工程标定精度。寿命预测输入适配已经完成，但新仿真数据没有真实寿命标签，不能据此宣称 RUL 精度通过验收。

## 数据选择规则

派生参数 CSV 仍保留在后台，用于原始状态量与同次 P 数据的配对预处理；健康评估、故障诊断、寿命预测、重演、遥测回放、多信号流、训练数据和仿真数据目录的用户选择框均隐藏派生参数，只显示原始状态量。
