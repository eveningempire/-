# 测试大纲审核说明

审核依据：用户最新提供的《健康管理系统测试大纲.docx》及当前项目源码。此次完成文档与代码核对，未执行现场验收或完整运行测试。合同、需求说明和设计文件的全文未单独提供，不能据模板转述断言已满足全部合同要求。

审核润色版保留原25张表、行列和合并关系、章节、图片及格式；合同要求原文及启动不超过60秒、显示延迟不超过1秒两项指标未降低。原文件未覆盖。

## 已修正的文档问题

- 结构树：已有整机根节点时，在其下新增测试分支；不再要求直接新增第二个整机。系统明确只允许一个根节点。
- 重演：先上传并登记CSV，再刷新重演事件。当前事件列表筛选数据管理中的数据集，实时告警事件不能直接按原步骤选择。
- 登录：从独立登录页操作，删除“点击右上角用户登录”的不匹配描述。
- 测试数据：明确D01、D02和关键点的预期值，替换“数据结果显示良好”等不能客观判定的表述。
- 图形界面：补齐两种分辨率和两种浏览器的测试前提；只在支持时间窗口的页面调整窗口。
- 性能计时：保留6000点工况，明确需要技术人员提前提供经校验的自动计时工具；人工操作不承担逐点测时。
- 故障隔离：明确为故障定位和隔离对象提示，不能理解为已执行实体设备隔离。
- 合格判定：未通过结果应保留；甲方对遗留问题的书面验收决定不能倒改成“测试通过”。

## 仍需关注的实现和验收风险

| 事项 | 代码核对发现 | 对验收的影响及建议 |
| --- | --- | --- |
| 结构树移动 | frontend/src/views/ComponentLibrary.vue 中父节点候选过滤从整机层直接筛选目标层，可能使子系统或单机的父节点选项为空 | 页面移动可能无法完成。保留页面移动要求，修复候选树过滤后实测，不能用接口操作替代页面通过。 |
| 结构合法性 | phm/structure_api.py 校验层级和循环，但新增重复唯一标识的数据库异常未纳入现有捕获；空名称主要依赖前端检查 | 直接接口提交的异常输入可能返回500或被接受。文档中的合法性要求保留，需测试和修复。 |
| 重演越界 | phm/fault_replay.py 的 create_replay 校验起止顺序和倍速，但未校验窗口是否超出事件范围 | 原要求“超范围拒绝”可能失败。已明确返回空曲线不算拒绝，建议补充边界校验。 |
| 角色权限及匿名访问 | 结构、重演、放行等函数视图未见统一身份和角色校验；settings.py 的中间件中未见统一业务权限拦截 | 数据集和采集接口已有部分校验，但不能代表全部接口安全。保留越权测试，逐接口验证；缺少CSRF导致的拒绝不能用作角色鉴权通过证据。 |
| 审计覆盖 | 当前AuditEvent写入主要见于phm/views.py的特定接入路径；登录、数据上传、结构修改等当前入口未见统一审计写入 | 访问日志不一定包含操作者、对象及操作结果。日志审计用例可能失败，需补齐记录链路。 |
| 1秒显示延迟 | 遥测页和告警页在请求结束后约1秒再发起轮询，还需叠加请求处理和图表渲染耗时 | 不能凭1秒轮询间隔判达标；最大值存在超标风险。需完成计时工具并实测，必要时修改刷新机制。 |
| 三维状态真实性 | Model3DTest.vue 包含前端预置仿真单元与状态；显示名称或状态不自动证明已连接实际仿真 | 已区分展示测试与实际状态联动。若合同要求监控真实运行状态，应核实数据源并补充实际联动证据。 |
| 信息推送 | 当前主要为平台内轮询显示及页面报告，外部订阅端推送未得到证明 | 若甲方所指“推送”包含外部接收系统，需确定接口和送达证据，不能以页面自动刷新替代。 |
| 算法基准 | Hier14、MSFG、PCA–iForest及健康/寿命模型的字段和运行依赖不同 | 需准备适配数据、固定模型版本和独立参考输出；模型运行成功不等于准确率合格。参考容差在测试前确定。 |
