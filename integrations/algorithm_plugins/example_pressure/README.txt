算法包导入示例：example_pressure

用途：验证“模型管理 -> 导入模型 / 算法”的离线导入和运行链路。
这不是经过甲方设备数据标定的正式诊断模型，阈值 0.8 仅用于演示。

导入步骤：
1. 将本目录压缩为 ZIP，ZIP 顶层目录必须保持 example_pressure。
2. 在平台进入“模型与可视化 -> 模型管理”，展开“导入模型 / 算法”。
3. 管理员选择 ZIP，点击“导入算法包”。成功后列表会显示“已导入，待验证”。
4. 在数据管理中选择一个至少 8 行、包含 pressure 列的已登记 CSV。
5. 在故障诊断页面选择“示例压力阈值诊断”，运行并检查全局诊断结果。

本包包含 weights.json，用于验证算法入口能读取同包模型资产。
正式使用时应替换算法代码、参数和模型资产，并按实际数据完成验证和标定。
