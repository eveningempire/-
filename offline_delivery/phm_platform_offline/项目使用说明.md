# 重复使用运载器健康管理平台——客户使用说明

文档版本:1.1  更新日期:2026-09-26  适用系统:Windows 10/11 64 位(离线单机部署)

## 1. 系统简介

本平台采用 Django + Vue 架构,面向重复使用运载器故障预测与健康管理(PHM),提供运载器结构管理、CSV 数据导入与回放、MATLAB/Simulink 实时采集、状态监测、异常告警、故障诊断、健康评估、寿命预测、事件重演、放行辅助评估及用户权限管理。

客户日常使用只需通过浏览器访问平台。MATLAB 接入采用 HTTP 上报方式,不要求 MATLAB Engine,也不由网页控制 MATLAB。

## 2. 交付目录

| `requirements-migration.txt` | 离线安装使用的 Python 依赖清单 |
| `frontend/` | Vue 前端源码和已构建页面 |

## 结构精简说明

交付包只保留运行、算法和现场数据所需内容；历史归档、重复算法副本和临时构建目录已移除。该整理不改变 Django、Hier14、健康评估适配器、MATLAB 接口或数据库的运行路径。

## 3. 运行环境

必需软件:

- Python 3.10(64 位;包内提供安装器);
- Chrome 或 Microsoft Edge;
- Windows PowerShell。

安装脚本会从本地文件安装 Node.js 22.18.0;正常使用已构建页面不需要运行 npm。MATLAB/Simulink 仅在实时采集时需要。默认单机模式使用 SQLite,不要求 Redis 或 MySQL,也不要求目标电脑连接互联网。

## 4. 首次安装

建议将 `phm_platform_offline` 完整解压到 `D:\PHM\phm_platform_offline`,预留足够空间。先双击根目录的 `install_runtime_offline.bat`,用包内安装器安装运行环境。安装结束后关闭并重新打开 PowerShell,进入解压后的根目录执行:

```powershell
cd D:\PHM\phm_platform_offline
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup_migration.ps1
```

脚本会使用包内 Python 3.10 安装器将运行时安装到项目目录 `runtime\python310`,再使用 `offline/python/` 中的本地 wheel 创建 `.venv`,全程不从互联网下载。看到 `Setup complete` 后再启动平台。

如果只需运行已构建页面、且前端依赖目录缺失,可跳过前端依赖检查:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup_migration.ps1 -SkipFrontend
```

交付包包含构建完成的网页,正常运行无需执行 `npm install`。如需重建前端,应先确认 `frontend/node_modules` 完整;离线环境不要直接使用普通 `npm install`,以免尝试访问网络。

如果 PowerShell 禁止激活脚本,可不激活,直接使用 `.\.venv\Scripts\python.exe` 执行命令。

创建管理员:

```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```

若数据库中已经有可用管理员,无需重复创建。上述命令会交互输入用户名、邮箱和密码;当前配置使用 Django 默认用户模型,创建后即具有超级用户权限。交付包中的旧版 `create_superuser.py` 和 `create_superuser.bat` 可能存在语法或环境兼容问题,请使用上述内置命令。

## 5. 启动与停止

双击 `start_phm_platform.bat`。脚本会检查环境、使用交付包内的前端成品、迁移数据库、启动服务并打开浏览器。仅当前端成品缺失时,脚本才会调用 Node.js 重新构建。

访问地址:

```text
http://127.0.0.1:8000/
```

启动后的服务器窗口请勿关闭。停止平台时双击 `stop_phm_platform.bat`,或在服务器窗口按 `Ctrl+C`。

手动启动命令:

```powershell
$env:USE_SQLITE = 'true'
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

## 6. 登录与权限

- 管理员:可创建采集会话、管理用户和结构、执行诊断与评估;
- 查看用户:可查看平台数据和结果,不能执行管理操作。

首次登录后建议修改默认密码,由管理员按实际人员分配权限。

## 7. 常用功能

### 7.1 CSV 导入与历史回放

进入数据管理或实时状态监测页面,选择 CSV 历史回放,上传或选择数据集,选择信号字段和速度后开始播放。CSV 建议包含时间列和至少一个数值信号,避免空值、`NaN` 和 `Infinity`。

### 7.2 实时异常告警

在 MATLAB 实时采集页面创建会话,再进入"异常告警中心",选择同一会话并开启实时检测。MATLAB 上报后,页面自动刷新告警、故障名称、严重程度与健康指数。

### 7.3 故障诊断与健康评估

选择数据集或实时会话后执行分析。结果会显示诊断类别、概率、趋势、健康度和证据。评估属于辅助决策,最终结论须由授权人员确认。

## 7.4 部署状态说明

综合态势页的四个状态灯反映的是当前交付包是否装载了可选算法或数据资产,不代表平台基础服务是否启动成功。未补充外部工程或未准备现场 CSV 时出现黄色状态是预期现象。

| 状态灯 | 交付包默认状态 | 原因与处理 |
| --- | --- | --- |
| 故障诊断 Hier14 | 已配置 | 交付包包含 `health-main/backend/algotest/hier14/predictor.py`、配置、`best_model.pth` 和 `scaler.pkl`。系统启动时会自动加载包内工程;如替换为其他版本,使用 `HEALTH_MAIN_DIR` 指向完整工程根目录。 |
| 健康评估适配器 | 已配置 | 交付包内已包含 `platform_handoff_20260911_v1/health_bundle`、模型注册表、健康模型和适配器代码。系统会自动查找包内资源;如需使用其他版本,可将 `PHM_PLATFORM_HANDOFF_DIR` 指向包含 `health_bundle` 子目录的目录。当前运行时若 scikit-learn 版本与模型生成版本不同,会显示兼容性提示,但适配器仍可加载。 |
| RUL Shadow 模型 | 已登记(开发) | 开发登记状态,模型尚未完成验证,不在线执行正式推理,属于预期状态。 |
| 仿真数据 / MATLAB | 已配置或待配置 | 交付包已包含 `integrations/simulation_assets/simulate_data_+1.zip`,平台默认以 ZIP 流式读取,不要求解压 3.45 GB 数据。若现场使用已解压 CSV,可放在项目根 `simulate/datacsv/`,或设置 `HEALTH_DATACSV_DIR` 指向 CSV 目录;也可用 `HEALTH_SIMULATION_ARCHIVE` 指向其他同结构 ZIP。MATLAB 实时接入仍需按第 8 节创建会话并运行上报脚本。 |

未配置现场 CSV 或 MATLAB 会话时,仿真数据状态灯仍可能显示黄色;这不代表平台基础服务或已打包的算法适配器故障。验收记录应注明现场数据尚未装载,或仿真资产采用 ZIP 流式模式。

## 8. MATLAB/Simulink 实时接入

### 8.1 工作方式

平台不会控制 MATLAB,也不依赖 MATLAB Engine。用户在 MATLAB 命令窗口执行平台生成的代码,MATLAB 通过 HTTP 将实际数据发送到当前采集会话。`phm_send_telemetry.m` 兼容 MATLAB 2012 及以上版本,使用 MATLAB 自带 Java HTTP 客户端和内置 JSON 编码,不使用 `webwrite`、`weboptions` 或联网安装的工具包。MATLAB 2012 请确认 `usejava('jvm')` 返回 `1`。

### 8.2 创建采集会话

1. 进入"实时状态监测";
2. 点击"选择数据源";
3. 选择"MATLAB 实时采集";
4. 输入本次试验名称;
5. 点击"创建并获取 MATLAB 参数";
6. 保存弹窗中的 Token(Token 只显示一次);
7. 点击"复制全部 MATLAB 代码"。

### 8.3 在 MATLAB 中执行

将平台复制的代码粘贴到 MATLAB 命令窗口。核心形式如下:

```matlab
addpath('D:/PHM/phm_platform/integrations/matlab');
addpath('D:/PHM/phm_platform/integrations/matlab/examples');

ingestUrl = 'http://127.0.0.1:8000/api/v1/phm/telemetry/sessions/<会话ID>/ingest/';
token = '<创建会话时显示的Token>';

testSample = struct('time', 0, 'pressure', 10.0, 'temperature', 25.0);
response = phm_send_telemetry(ingestUrl, token, testSample);
disp(response);
```

将 `D:/PHM/phm_platform` 替换为实际目录。测试成功后,平台采样数会增加。

### 8.4 接入实际 MATLAB/Simulink 项目

在采样循环、回调或 MATLAB S-Function 中组织实际信号:

```matlab
sample = struct( ...
    'time', t, ...
    'pressure', pressure, ...
    'temperature', temperature);
response = phm_send_telemetry(ingestUrl, token, sample);
```

要求:

- `time` 严格递增;
- 所有字段均为有限标量数值;
- 同一会话的字段名称和数量保持一致;
- 不发送 `NaN`、`Inf` 或字符串;
- 高频仿真建议缓存后每 0.2~1 秒批量发送;
- 仿真时间重新从 0 开始时新建会话;
- MATLAB 在另一台电脑时,将 `127.0.0.1` 改为平台服务器 IP,并确保 8000 端口可访问。

完成后在平台点击"结束采集"。结束的会话不能继续写入,但仍可查看和导出。

## 9. 数据备份

默认数据库为根目录的 `db.sqlite3`,上传文件位于 `media/`。停止服务后至少备份:

```text
db.sqlite3
media\
config\
```

不要只备份数据库而遗漏 `media`,否则文件记录可能找不到实际文件。

## 10. 常见问题

### 页面打不开

确认启动窗口仍在运行、地址为 `http://127.0.0.1:8000/`,并检查 8000 端口是否被占用。

### 找不到 `.venv\Scripts\python.exe`

确认交付包已完整解压;若 `.venv` 确实缺失,请按第 4 节运行离线安装脚本。如果提示 `offline/python` 缺少 wheel,请使用包含离线依赖的修正版交付包。不要在目标电脑执行联网安装命令。

### 前端修改后没有变化

重新启动平台,并在浏览器按 `Ctrl+F5` 强制刷新。

### MATLAB 找不到 `phm_send_telemetry`

确认 `addpath` 指向正确目录,然后运行:

```matlab
which phm_send_telemetry
```

### Token 无效

Token 可能复制不完整、属于其他会话或会话已结束。请创建新会话并使用新 Token。

### time 必须严格递增

同一会话不能重复或倒退时间。仿真重新开始时创建新会话。

### 一直显示等待数据

先执行单条测试代码;确认 URL、会话 ID、Token 和平台服务正确。跨电脑使用时检查 IP、防火墙与 8000 端口。

## 11. 安全建议

- 不要将 `.env`、数据库、Token 或客户数据上传到公共仓库;
- 正式部署应关闭调试模式并使用强密码;
- 对外服务建议使用 HTTPS 和反向代理;
- 定期备份数据库与媒体文件;
- Token 仅用于单个实时会话;
- 所有评估和放行结果须经授权人员复核。

## 12. 技术支持信息

反馈问题时请提供 Windows、Python、Node.js、MATLAB 版本,问题页面与复现步骤,启动窗口错误、浏览器控制台错误及 `logs/django.log` 对应日志。请勿提供真实密码或完整 Token。



启动与停止统一使用 `start_phm_platform.bat` 和 `stop_phm_platform.bat`。卸载时运行 `uninstall_phm_platform.bat`;该脚本只删除项目虚拟环境和包内运行时,不删除数据库、媒体文件或用户配置。
