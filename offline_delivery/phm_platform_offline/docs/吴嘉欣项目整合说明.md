# 吴嘉欣项目整合说明

## 整合范围

项目平台保留 Django + Vue 主架构,将可复用的结构数据、故障知识、算法资产和仿真资源统一放入 `integrations/algorithm_assets`、`health-main`、`platform_handoff_20260911_v1` 与 `integrations/matlab`。

## 当前可用功能

- FMECA 故障知识库:支持记录展示、筛选和详情查看。
- 运载器 PBS 结构树:支持节点查询、编辑、新增和删除。
- Hier14 故障诊断:使用包内 health-main 工程和权重,缺少完整模型时返回明确原因。
- 健康评估:支持 CDPCA-GA、AE-GMM 和 GCN + RBD,健康指数图包含坐标和刻度。
- 寿命预测:使用 health-main 集成模型,部件选择显示 14 个实际部件名称,RUL 单位为小时(h)。
- MATLAB 接入:采用 HTTP 上报,不依赖 MATLAB Engine;示例位于 `integrations/matlab`。

## 资产状态

启动后可在首页查看 Hier14、健康评估适配器和仿真资源状态。状态灯反映当前包内资源是否被成功加载,不代表算法精度验收结果。正式验收应使用标注试验数据记录诊断、健康评估和 RUL 指标。

## 离线运行

完整交付包包含 Python 3.10.11、离线依赖、前端成品和模型资产。运行 `setup_migration.ps1` 后使用 `start_phm_platform.bat` 启动,不需要联网或下载额外包。
